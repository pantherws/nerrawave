# Nerrawave

Nerrawave is an AI-powered speech to text transcription platform designed to automatically transcribe pre-recorded and 
uploaded audio and video files.

The system focuses on:

• fast transcription
• high accuracy
• extraction of key information from transcripts using AI
• minimal user interaction

The product is marketed mainly to industries that record meetings, such as market researchers.

# Development Instructions

Cursor should follow these principles when writing code:

1. Prioritize speed and minimal dependencies.
2. Code must be modular and easy to maintain.
3. Avoid unnecessary libraries.
4. Backend should be scalable for cloud deployment.

# Goal of the Project

Build a fast AI speech to text transcripton platform capable of transcribing audio and video files.

The system should feel simple to the user but use advanced processing internally.
